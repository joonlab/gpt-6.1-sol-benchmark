# 추론 트랙: 수학·논리 문제 정답률

정답이 하나로 정해진 수학·논리 문제를 gpt-6.1-sol 이 얼마나 맞히는지, 그 과정에서 추론 토큰과 시간을 얼마나 쓰는지 측정했습니다.
비교 대상은 gpt-6-sol, gpt-6-astra, gpt-6-luna, gpt-5.6-sol 입니다. 측정일은 2026-09-30 입니다.

## 요약

- gpt-6.1-sol 은 effort=high 에서 88/88, medium 에서 86/88 을 맞혔습니다. medium 의 오답 2건은 둘 다 같은 문항(H04, 1,000번 소수 판정)에서 나왔고, H04 를 빼면 medium 도 86/86 입니다.
- 상위 4개 모델(gpt-6.1-sol, gpt-6-sol, gpt-6-astra, gpt-5.6-sol)은 이 문제 세트로는 **구분 불가**입니다. 8개 셀이 84~88건 정답이고(gpt-5.6-sol high 는 관측 87건 중 86건), 차이는 거의 H04 와 X02 두 문항에서만 났습니다.
- 확실히 낮게 나온 모델은 gpt-6-luna 하나입니다(medium 72/88, high 76/88).
- H04 를 제외한 평균 추론 토큰(medium)은 gpt-6.1-sol 179개로, gpt-6-sol(286)의 약 0.6배, gpt-5.6-sol(373)의 약 절반입니다.

## 1. 무엇을 테스트했나

직접 만든 44문항을 5개 모델에 풀게 하고, 마지막 줄의 답을 정답과 기계적으로 비교했습니다.

| 난이도 | 문항 수 | 예 |
|---|---|---|
| easy (E01~E10) | 10 | 7560 의 약수 개수, 3^100 mod 13, 방망이와 공 가격(함정), 우물 달팽이(함정) |
| medium (M01~M10) | 10 | BANANAS 배열 수, 장애물이 있는 격자 경로, 문 6개 몬티홀, 기사/건달 5명 |
| hard (H01~H14) | 14 | 자릿수 합 29, 제약 있는 교란순열, 4×7 도미노 타일링, H04 n²+n+43 이 소수가 아닌 n 의 합, 7^(7^7) 의 끝 세 자리 |
| xhard (X01~X10) | 10 | 행·열 합이 2인 5×5 0/1 행렬 수, 5×5 판에 킹 6개 배치, 도박꾼 파산 확률, C(2026,1013) mod 1009 |

범주 분포는 조합 15, 정수론 12, 확률 9, 산술 4, 함정 3, 논리 1 입니다. 조합과 정수론에 쏠려 있습니다.

정답 확정
- 모든 정답은 프로그램으로 직접 계산하거나 전수 탐색으로 센 값입니다. 손으로 적은 정답은 없습니다.
- 해가 하나여야 하는 문항(M07 기사/건달)은 해가 정확히 하나인지 확인했습니다.
- 방망이와 공, 몬티홀, 도미노 타일링 같은 유명 문제는 수치를 바꿨습니다(예: 문 6개 몬티홀, 합계 $1.40 / 차이 $1.20). 외운 답으로는 못 맞히게 하려는 목적입니다.

## 2. 방법

| 항목 | 값 |
|---|---|
| 모델 | gpt-6.1-sol, gpt-6-sol, gpt-6-astra, gpt-6-luna, gpt-5.6-sol |
| reasoning effort | medium, high |
| 반복 N | 문항당 2회 |
| 셀 수 | 44문항 × 5모델 × 2 effort × 2회 = 880 |
| 실행 환경 | ChatGPT Pro 구독의 Codex 환경, 동시 실행 3, 호출당 제한시간 900초 |
| 프롬프트 | 영어. 마지막 줄을 `ANSWER: <정수 또는 기약분수>` 로 쓰도록 강제 |
| 채점 | 응답의 마지막 `ANSWER:` 줄에서 숫자를 뽑아 분수 동치로 비교(결정론). LLM 판정은 쓰지 않았습니다 |
| 추론 토큰 | 응답 usage 의 `reasoning_tokens` |
| 시간 | 요청부터 응답 완료까지 클라이언트에서 잰 벽시계 시간(네트워크·대기 포함) |

프롬프트 틀은 다음과 같습니다.

```
Solve the following problem.

{문항}

Keep the explanation brief. The final line of your response must be exactly
ANSWER: <value>
where <value> is an integer or a reduced fraction p/q, with no units or extra words.
```

채점 세부
- `ANSWER:` 줄이 없으면 오답으로 치고 `n_unparsed` 로 따로 셉니다.
- `10 cents` 처럼 뒤에 단위가 붙어도 앞의 숫자만 읽습니다. 형식을 정확히 지켰는지는 `strict_format_rate` 로 따로 셉니다.
- 정확도 분모는 **답을 관측한 기록**만입니다. 응답 도중 연결이 끊겨 완료 신호와 토큰 사용량이 오지 않은 기록은 오답이 아니라 관측 실패로 보고 분모에서 뺐습니다(6절).

## 4. gpt-6.1-sol 관찰

**effort medium → high**
- 정답이 86 → 88 로 늘었지만 달라진 건 H04 2건뿐이라 구분 불가입니다. 다만 H04 에서 medium 은 두 번 다 틀리고 high 는 두 번 다 맞혀 방향은 일관됐습니다(관측).
- H04 제외 추론 토큰 평균이 179 → 263(약 1.5배), 시간 평균이 12.2 → 15.0초로 늘었습니다.
- 두 반복의 판정이 모든 문항에서 같았습니다(medium·high 모두 일관성 1.0).

**틀린 문항은 H04 하나**

> H04 (hard, 정수론) Let S be the set of integers n with 1 <= n <= 1000 such that n^2 + n + 43 is NOT prime. What is the sum of the elements of S?
> 정답 449402

| effort | 회차 | 답 | 추론 토큰 | 시간(초) |
|---|---|---|---|---|
| medium | 0 | 444586 (오답) | 18,128 | 586.0 |
| medium | 1 | 448913 (오답) | 18,486 | 597.6 |
| high | 0 | 449402 (정답) | 15,446 | 499.3 |
| high | 1 | 449402 (정답) | 15,538 | 503.0 |

- 이 문항은 1,000번의 소수 판정을 도구 없이 해야 합니다. 추론보다는 대량 계산 능력을 재는 문항에 가깝습니다.
- medium 의 두 오답은 서로 다르고, 정답과 각각 4,816, 489 차이가 납니다.
- 같은 문항에서 다른 모델의 반응은 셋으로 갈렸습니다(관측). gpt-6-astra 와 gpt-5.6-sol 은 오래 계산해서 답을 냈지만 대부분 틀렸고(astra medium 1/2 정답), gpt-6-sol 은 4번 모두 답을 확정하지 않아 `ANSWER:` 줄 자체가 없었으며(파싱 실패 4건이 전부 이것), gpt-6-luna 는 447000, 414000 처럼 끝자리가 000인 어림값을 냈습니다.
- gpt-6.1-sol high 가 H04 를 맞힌 건 사실이지만 n=2 입니다. 이런 문항은 실무에서는 코드 실행 도구를 붙여 푸는 게 맞다고 봅니다(해석).

**시간은 토큰과 따로 놀았습니다**
- 쉬운 문항 20건의 벽시계 중앙값이 gpt-6.1-sol medium 5.5초로, 다른 네 모델 medium(3.8~4.7초)보다 길었습니다. 추론 토큰 중앙값은 35.5개로 오히려 적은 편이었습니다(관측).
- 첫 토큰 대기나 출력 속도 차이일 수도 있고, 같은 시간대에 돌린 다른 측정의 부하 때문일 수도 있습니다. 이 데이터로는 둘을 분리할 수 없습니다.

## 5. 한계

- 44문항 × 2회라 셀당 88건이고, 1건이 약 1.1%p 입니다. 상위 4개 모델 간 차이와 gpt-6.1-sol 의 effort 간 차이는 통계적으로 구분되지 않습니다.
- 상위 모델이 천장에 닿았습니다. H04 를 빼면 변별 문항이 X02 하나뿐이고, 경시대회 최상위 난도의 세트가 아닙니다.
- 상위 모델을 가른 H04 는 추론보다 도구 없는 대량 계산을 잽니다. 이 한 문항으로 추론력 순위를 매기면 안 됩니다.
- xhard 10문항은 처음 34문항(easy·medium·hard)의 결과에서 상위 모델이 천장에 붙은 것을 보고 **나중에 추가**했습니다. 34문항 기준 정확도(`accuracy_base34`)를 함께 보시기 바랍니다.
- 범주가 조합·정수론에 쏠려 있고(27/44), 논리 문항은 1개뿐입니다.
- 시간은 ChatGPT Pro 구독의 Codex 환경에서 잰 벽시계이고 다른 측정과 동시에 돌렸습니다. 공식 API 의 지연과 다를 수 있습니다. 출력 길이 상한 설정도 이 환경에서는 적용되지 않았습니다.
- 알려진 유형의 수치를 바꾼 문항이라 학습 데이터 오염을 완전히 배제할 수는 없습니다.

## 6. 끊긴 응답 처리

전체 884건의 호출 기록 중 5건이 응답 완료 신호 없이 끊겼습니다(모두 70초 이상 걸린 긴 호출). 이 기록은 오답이 아니라 관측 실패로 분류해 정확도 분모에서 뺐고, 같은 셀을 다시 실행해 성공한 기록이 있으면 그 기록을 썼습니다. gpt-5.6-sol high 의 H04 2회차는 재실행에서도 끊겨 값이 없으므로, 그 셀은 관측 87건 기준입니다(`results.csv` 에서 `observed=false`, 0점으로 채우지 않음).
